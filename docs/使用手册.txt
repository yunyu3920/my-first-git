================================================================================
                            temu-bot  使用手册
================================================================================

给自己和用这套工具的人看。不需要懂编程，照着做就行。


================================================================================
一、这是干什么的
================================================================================

在网页上点几下，把一批商品铺到 Temu 半托管（走「店小秘」后台）。

干的活是这四件：

  收集文件             把一堆素材图整理成一张「商品信息表」
  自动上架             按表把商品一个个建出来（复制模板 + 换主图 + 填货号 + 改标题）
  图片批处理生成清单   给图片发 11 位唯一 ID，并存一份「ID 对照原名」的清单
  设置                 改配置（表在哪、速度、浏览器）

商品ID、状态、问题项会**自动写回表格**，不用手工抄。


================================================================================
二、准备
================================================================================

  必须装：  Google Chrome          （登录店小秘用的是系统 Chrome）

  不用装：  Python                 （绿色版不用，源码版才需要）
            Node / WPS / Excel     （都不用）

  系统：    Windows 10 / 11


================================================================================
三、第一次用（大概 5 分钟）
================================================================================

1. 启动
------------------------------------------------------------------------------
   双击「启动 temu-bot.bat」
   （绿色版在解压出来的 temu-bot 文件夹里；源码版在 D:\temu_bot\）

   会弹一个黑窗口，然后浏览器自动打开控制台。

   ※ 那个黑窗口就是程序本体，别关它。
   ※ 要停程序：关掉黑窗口，或者在窗口里按 Ctrl+C。
   ※ 浏览器页面关掉没关系，重新打开 http://127.0.0.1:8765 就行。


2. 告诉程序表格在哪
------------------------------------------------------------------------------
   控制台左边点「设置」→「路径」→「商品信息表」，
   填上你这台电脑上那张表的完整路径，比如：

       C:\Users\A\Desktop\yyy\商品信息表.xlsx

   然后点「保存设置」。保存后顶栏会显示表名和行数。

   ※ 新用户还没设置时，程序会自动在**程序目录、桌面、桌面下一层文件夹**里
     找 `商品信息表.xlsx`；找到后会直接显示在顶栏。确认是这张表就点「保存设置」固定下来。
   ※ 表里只有一张工作表、但名字不是 `Sheet1` 时，程序会自动用唯一那张；
     有多张工作表时，请在设置里把工作表名改对。


3. 登录店小秘（第一次）
------------------------------------------------------------------------------
   不用手动点登录文件。直接在控制台点「开始上架」：
     → 程序发现还没登录过，会自动弹出浏览器
     → 在窗口里正常登录店小秘
     → 登录成功后程序会自动继续上架

   登录态会自动存下来，以后长期复用。
   如果 10 分钟内没有登录完成，程序会**取消这次上架**并关掉登录窗口，
   一行都不会跑；重新点「开始上架」即可。
   要换账号 / 重新登录时，也可以单独双击「1-登录店小秘.bat」。


4. 自检一下
------------------------------------------------------------------------------
   控制台「设置」页面最下面，或者命令行跑  temu-bot doctor
   看到全是 PASS（除了「AI 标题」可能是 WARN）就没问题。


================================================================================
四、日常怎么用
================================================================================

   ① 收集文件           ② 图片批处理生成清单        ③ 自动上架
   把素材整理成表  →    给图发 ID + 导清单     →   按表建商品并发布

   （② 和 ① 的先后可以按你的习惯来）


----------------------------------------------------------------------
4.1  收集文件 —— 把素材文件夹变成商品信息表
----------------------------------------------------------------------

前提：素材文件夹里的图片是成对的

    00742093597.jpg             ← 主图
    00742093597-素材图.jpg       ← 素材图

一对 = 一行商品。只有「-素材图」没有主图的，不算一行。

操作：

   1) 选文件夹    —— 点「选择文件夹」，弹系统文件夹窗口，选素材目录
   2) 填 店铺名、模板 spu、主图索引
                     （店铺名和模板 SPU 会记住上次填的，下次自动带出来）
   3) 选「图片文件名清单」（可选，见下面）
   4) 勾「强制生成素材图」（默认勾着 = 缺素材图就用主图生成一张）
   5) 点「扫描预览」  —— 只读，不写文件。看看会收成哪些行、跳过哪些
   6) 确认没错 → 点「生成表格」

   ※ 生成的是新文件（比如 商品信息表-20261016-193000.xlsx），绝不覆盖已有的表
   ※ 生成完可以点「用这张表上架」，直接把它设成当前表

   图片文件名清单（自动填中英文标题）
   ------------------------------------------------
   点「选择文件」选那份 图片文件名清单.xlsx（或 .csv），程序会：

     拿图片名的 11 位 ID，去清单 A 列里找，
       找到 → B 列（中文）填进第 17 列，英文列填进第 18 列
       找不到 → 那两格留空，扫描预览里会写明是哪几个 ID

   就是原来那个公式 =VLOOKUP(I2,图片文件名清单!$A:$B,2,0)，但程序里更稳：
   ID 一律按**文本**比，前导 0 不会丢（0 开头的 ID 不会对不上）。

   英文列的位置不用你填：程序自动在 C 列之后找"像英文的"那一列
   （你的清单放在 J 列）。如果英文整体比 ID 错了一行（第一行就是英文标题），
   程序会自动对齐，预览里会提示一句。

   不选清单也能生成表，17/18 列就是空的。


----------------------------------------------------------------------
4.2  图片批处理生成清单 —— 发 ID + 导对照清单
----------------------------------------------------------------------

这一页只有一件事：「11 位 ID - 导表 - 保留 11 位 ID」。

它一步做完三件事：

   1) 给每张图发一个 11 位唯一 ID，文件名变成  12345678901-原文件名.jpg
   2) 导出 图片文件名清单.csv 和 .xlsx（记录 ID 对应原名）
   3) 把文件名还原成纯 11 位 ID：  12345678901.jpg

怎么用：选文件夹 → 点「预览」看清单 → 没错就点「执行」。

   ※ 已经带 11 位 ID 前缀的图会沿用原 ID，不会叠出第二个
     —— 所以重复跑是安全的
   ※ 发出去的 ID 永不重发（有台账记着）
   ※ 清单如果已存在，会先备份成 .bak-时间戳，不会覆盖
   ※ 清单正被 Excel/WPS 打开着的话，会跳过它并提示你先关掉


----------------------------------------------------------------------
4.3  自动上架
----------------------------------------------------------------------

在「自动上架」页，按 ①②③ 走：

   ① 选择表格
        一般已经填好了（就是设置页那个路径）。

   ② 选择要跑的行
        带搜索和筛选。每行会标一种状态：

          新建          表里没有商品ID → 会复制模板建一个新商品 + 换主图
          已有商品      表里有商品ID   → 是重试/续跑，不会复制
          SKU货号 缺    （红色）第 9 列是空的 → 跑不了，先去表里补上

   ③ 预览并运行
        勾一行，这里会显示它的主图缩略图、货号、图片合不合规、店铺、状态。
        先看清楚图有没有配错。

        然后看下面几个开关：

          店铺核对             「核对店小秘店铺」= 只查不跑，立刻告诉你表里的店
                               在你的账号里找不找得到。
                               ※ 点「开始」时程序会**自动先核对一次**：
                                 对了才开始上架；不对就停下提醒，一行都不跑。
          自己打开店小秘       「我自己打开店小秘」= 弹浏览器自己去登录/切店，
                               不点上架。
          开始前自动打开店小秘  默认勾上 —— 点「开始」时顺带弹浏览器让你看
                               店铺对不对。不想自动弹就取消勾选，用上面那个
                               按钮自己开。

          运行方式             默认「真实执行」
                               ※ 点「开始」就真的会建商品。只看不跑就切「干跑」

          保存后的动作         默认「2 = 立即发布」
                               ※ 建完直接发到 Temu。想先留着就切「1 = 仅保存」

          强制换图             默认勾上 —— 每行都重新传图换图
          自动清理图片         默认勾上 —— 上架成功后删本地中间产物，并且
                               （只在「立即发布」时）把这次传到店小秘图片
                               空间里的图也删掉，省空间

        点「开始」→ 先核对店铺 → 对了才弹确认框，把里面的字读完再点确定。

   ★ 一次别勾太多行！
     Temu 对每家店有「每日发品额度」，满了当天就发不了了。
     建议一次 5～10 行，跑完看结果再继续。

   跑完看结果区：每一步都应该是 OK。最后一步 WRITEBACK 是把商品ID/状态写回表格，
   这是防重复铺货的闸门 —— 表里没有商品ID 的行，下次跑还会当「新建」，就重复了。

   ★ 同样的错误只显示一次
     结果区按「错误内容」分组：一批行错在同一个地方，只会出现一张卡片，
     标题写着「第 2–98 行，共 97 行，错误完全相同」，不会把同一句话刷几十遍。
     成功的行也收在一起，点开才看商品ID。


================================================================================
五、几条必须知道的规矩
================================================================================

1. 默认就是「真实执行 + 立即发布」
   所以点「开始」之前一定先看预览。
   想只看不写，把运行方式切到「干跑」。

2. 店铺是按表格认的，不是按配置认的
   表里第 10 列写的是哪家店，程序就去找「你登录的账号里有没有这家店」：
     找得到 → 照跑
     找不到 → 停下，并告诉你账号里实际有哪些店
   所以你登录的店铺随时可以换，程序不会有意见。
   对不上时程序会自动打开店小秘让你登好再来。

3. 只换主图，颜色/规格一个字都不动

     模板： [主图A, 展示1, 展示2, 展示3, 展示4]
     结果： [新主图, 展示1, 展示2, 展示3, 展示4]

   模板的其它展示图原样保留。

4. SKU 货号用表格第 9 列，不是模板的
   第 9 列空着 → 上架前就会被挡下来。

5. 图片规格（Temu 要求）
     主图 / 轮播图： 3:4、宽 >= 1340、高 >= 1785、小于 2MB
     素材图：        800 x 800
   程序会自动按规格出图，原图不动。


================================================================================
六、表格长什么样
================================================================================

一共 20 列，常用的这几列：

   第 1 列    文件夹路径                     你填（图片放在哪）
   第 2 列    主图                           你填（文件名）
   第 8 列    素材图                         你填（文件名）
   第 9 列    一键生成SKU货号前缀编码        你填（不填跑不了）
   第 10 列   店铺名                         你填（程序拿它对店铺）
   第 11 列   模板产品SPUID                  你填（复制谁当模板）
   第 13 列   商品ID                         程序回写
   第 14 列   状态                           程序回写
   第 16 列   问题项                         程序回写（失败原因）
   第 17/18 列 中文标题 / 英文标题            你填


================================================================================
七、出问题了怎么办
================================================================================

  表读不出来 / 顶栏显示「表格读取失败」
       → 设置 → 路径，确认商品信息表路径对不对
       → 新用户没设置路径时，程序会自动在桌面附近找 商品信息表.xlsx；
         鼠标停在红字上能看到具体原因
       → 表只有一张工作表但名字不是 Sheet1：程序会自动用那张；
         多张工作表：到设置里把工作表名改对

  提示「没有任何登录身份的账号里有这家店」
       → 表里第 10 列的店名和你登录的账号对不上。
         程序会顺手打开店小秘，登好把窗口关掉再重来

  提示「找不到模板 SPU」
       → 表里第 11 列的 SPU 不是这家店的，或者写错了

  提示「每日发品额度已满」
       → 这家店今天的额度用完了，明天再发，或者找买手提额

  WRITEBACK 那一步是红色叉
       → 表格正被 Excel/WPS 打开着。关掉表格，跑：
             temu-bot table writeback --live
         补写。上架本身没失败

  点某个按钮弹「Not Found」
       → 控制台还开着改代码之前的旧进程。
         把黑窗口关掉，重新双击「启动 temu-bot.bat」

  提示找不到图片
       → 表里写的文件名和文件夹里的对不上（大小写、扩展名也算）

  表里夹着空白行 / 只填了一半的行
       → 不用管，也不会打断上架。程序只把「文件夹路径」和「主图」都填了的
         当成一行商品，其余的自动跳过。行列表顶部会写明跳过了第几行，
         其他行照常跑

  上架时提示「疑似店小秘接口变更」/ 接口 404
       → 店小秘那边可能改接口了。点上架页「店铺核对」旁边的「接口自检」，
         看是哪一项不通过；把结果发给开发者（或 AI）处理，处理完再重试。
         程序不会跑到一半乱建商品——自检不过会直接停下

  登录态过期了
       → 直接在控制台点「开始上架」，程序会自动打开登录窗口；登录成功后自动继续
       → 也可以单独双击「1-登录店小秘.bat」重新登一次


================================================================================
八、文件夹里都是什么（绿色版）
================================================================================

   temu-bot\
   ├─ 启动 temu-bot.bat        <- 平时双击这个
   ├─ 1-登录店小秘.bat
   ├─ 使用说明.txt
   ├─ 使用手册.txt             <- 就是本文件
   ├─ temu-bot.exe
   ├─ config\                  设置（可以用记事本改）
   ├─ data\                    日志、备份、ID 台账、登录态    ★ 别外传
   ├─ profiles\                浏览器配置（登录态）          ★ 别外传
   ├─ work\                    中间产物，可以随时删
   └─ _internal\               程序运行时，别动

   ★ data\ 和 profiles\ 别发给别人、也别传网盘 —— 里面是你店铺的登录态


================================================================================
九、升级到新版
================================================================================

   保留 config\、data\、profiles\ 三个目录，其余整个覆盖。

   最省事的做法：
     1) 新版压成 zip
     2) 解压到原来那个文件夹，提示「文件已存在」时选「替换目标中的文件」
        （别先删旧文件夹再解压 —— 那样登录态和 ID 台账就没了）
     3) 完事


================================================================================
十、别做这些事
================================================================================

   ×  别把 data\ 或 profiles\ 发给别人 / 传网盘
   ×  别在表格开着 Excel/WPS 的时候跑上架（回写会失败）
   ×  别一次勾几十行一起发（每日发品额度会满）
   ×  别把 data\state\used_ids.txt（ID 台账）删掉
      —— 删了可能把用过的号重新发出去，图片撞号
   ×  同一个商品别重复建（表里的商品ID 就是防这个的，别手工清掉）
