## SKU 重命名（命令行）

给每张图发一个 **11 位数字的唯一 ID**，四种模式。
**网页上只用得到第 4 种**（那个「11 位 ID - 导表 - 保留 11 位 ID」就是它）。

| 模式 | 名字 | 结果 |
|---|---|---|
| `id-only` | 1 - 纯 11 位 ID | `裙子.jpg` → `12345678901.jpg`（原名丢弃） |
| `id-prefix` | 2 - 11 位 ID-原文件名 | `裙子.jpg` → `12345678901-裙子.jpg` |
| `strip-id` | 3 - 去掉 `-` 后面的内容 | `12345678901-裙子.jpg` → `12345678901.jpg` |
| `roundtrip` | 4 - 加 ID → 导清单 → 还原 | 文件最终是**纯 11 位 ID**，另外留一份 ID↔原名的清单 |

三条容易踩的规矩（都是从原 `.bat` 脚本的坑里改出来的）：

1. **已经带 11 位数字前缀的文件不再叠第二个 ID**。
   否则重复跑一次就变成 `新ID-旧ID-原名`，导出的清单直接作废。
   沿用下来的 ID 会**补记进台账**，免得以后发给别的图。
2. **模式 3 只在第一个 `-` 前面正好是 11 位纯数字时才裁**。
   原脚本是无条件按第一个 `-` 截断的，文件名里自带 `-` 的会被误伤。
3. 目标名已存在、或名字压根没变 → **跳过**，不算错。

### ID 台账在哪里

```
D:\temu_bot\data\state\used_ids.txt
```

一行一个 ID，UTF-8 无 BOM，**只增不删**。**这些号一旦发出去就永远不能重发**——
文件名上的 ID 是图片的唯一身份，重发会让两张图撞号。

生成用的是**密码学随机数**（`secrets`），不是 `random`（原脚本用 `%random%`，可预测）。

**桌面那份 `used_ids.txt` 会被自动合并进来**：第一次使用时，程序把
`C:\Users\A\Desktop\图片批处理工具箱\app\used_ids.txt` 里的 ID **并进项目台账**
（取并集，只增不删）。那份里有 130 个已经发出去的历史 ID，搬家时不能丢。
取并集是幂等的，所以不用做一次性迁移，也不用记"迁过了没有"。

看一眼现在有多少个号：

```bat
temu-bot toolbox ids
```

## 导出图片清单

按文件名的**第一个 `-`** 拆成「数字前缀 / 中文后缀」两列，输出两份（可以只出其中一份）。

**网页上它并进了那个 ID 动作里**（模式 4 的中间一步），页面上的两个勾选框
「生成 CSV」「生成 XLSX」控制的就是它。**两个都不勾**时：改名那部分照样跑完
（文件最后仍是纯 11 位 ID），只把导出那一步记成失败并写明原因 ——
不会让整件事半途而废。

### `图片文件名清单.csv` —— 与老脚本逐字节一致

**这是刻意做成的**，下游流程认的就是这些字节，别"顺手修掉"：

- **GBK（代码页 936）、无 BOM、CRLF**
- 表头 `"数字前缀","中文后缀" ` —— **行尾有一个空格**
- 数据行 `"前缀","后缀" ` —— **同样行尾一个空格**
- 那个空格原本是 `cmd` 的 `echo ... >> 文件` 把重定向前的空格也写进去了，
  属于原样复刻
- 值里的 `"` 写成 `""`
- 文件名里有 GBK 表示不了的字符（emoji）→ 写成 `?` 并继续，**不中断**
- 写完**回读核对行数**，不符就报错

拆分规则：`-` 在**开头**或**没有** `-` 时，整个名字当前缀、后缀空；
后面还有 `-` 的话留在后缀里（`带着-横杠-的名字` → 前缀 `带着`、后缀 `横杠-的名字`）。

### `图片文件名清单.xlsx`

工作表名 `图片文件名清单`，A 列数字前缀 / B 列中文后缀。表头**加粗**、
**冻结首行**、带**自动筛选**，A 列窄 B 列宽。同样写完回读校验。

### 两条安全规矩

- **同名文件不会被覆盖**：目标已存在就先改名成 `<原名>.bak-<时间戳>` ——
  那份清单是原文件名的唯一记录，覆盖掉就找不回来了。
- **旧清单被 Excel/WPS 打开着**（改名失败）→ 那一个目标记「失败」并跳过，
  另一个照常，整个导出不会崩。

## 格式转换（命令行）

把选定文件夹里的图转成 png / jpg / webp / avif。**页面上没有这一块了。**

- **质量**默认 100（1–100）。只对 jpg / webp / avif 生效；**png 是无损的**，
  这个值只表示"开到最大压缩"。
- **输出目录留空 = 跟源文件同目录**。
- **同批撞名加 `_1`、`_2`**（比如两个子文件夹里有同名图，一起转到同一输出目录）。
- **jpeg 会把透明铺成白底**（jpeg 没有透明通道，否则透明处会变黑块）。
- **两种跳过**（都算"跳过"，不算错）：
  - 目标路径与源文件是同一个 —— 这拦的是"同一个目录里既转又扫，
    把自己刚转出来的 webp 再转一遍"那种越转越多
  - 目标已存在且没勾「覆盖」
- **原图只读，不删源文件**。这轮也不提供删除功能（少一个依赖，也少一份误删风险）。

**已知差异**：

- **HEIC 转不了**：Pillow 没有 HEIC 解码器（桌面工具箱靠 sharp 才读得了）。
  这类文件会被扫到，但会显示「打不开」并写明原因。
- **动图只尽力保留多帧**（webp/png 用 `save_all`），不保证与 sharp 完全一致。

## Excel 合并（命令行）

把文件夹里所有工作簿的**所有工作表**纵向拼成一个 —— **不加表头、不去重、不做对齐**，
纯粹是一行接一行。**页面上没有这一块了。**

- 取 `.xls` + `.xlsx`（**只看这一层，不递归**），排除 `~$` 开头的 Excel 锁文件，
  排除**输出文件自己**（否则第二次跑会把上次的结果再合一遍）。
- 勾「每个工作簿前插入一行来源文件名」→ 在该工作簿内容**前面插一行**、
  只在 A 列放文件名（**每个工作簿一行，不是每个工作表一行**）。
- 默认输出 `<文件夹>\MergedExcel.xlsx`。
- **写完回读校验**：行数不对或表是空的就报错，不产出一张说不清的表。

**`.xls`（老格式）合不了** —— openpyxl 读不了它。会被列出来并记「跳过」，
原因写明。桌面版是靠 WPS/Excel 的 COM 才读得了 `.xls` 的，那正是这套程序要摆脱的东西。

## 命令行

```bat
:: 看台账（有多少个号、旧台账合进来没有）
temu-bot toolbox ids

:: 页面上那件事（加 ID → 导清单 → 还原成纯 ID）
temu-bot toolbox rename --dir "D:\素材" --mode roundtrip
temu-bot toolbox rename --dir "D:\素材" --mode roundtrip --live

:: SKU 重命名的另外三种模式（页面上没摆）
temu-bot toolbox rename --dir "D:\素材" --mode id-prefix
temu-bot toolbox rename --dir "D:\素材" --mode id-only --live

:: 只导出清单，不改名
temu-bot toolbox export --dir "D:\素材" --format both
temu-bot toolbox export --dir "D:\素材" --format xlsx --live

:: 格式转换
temu-bot toolbox convert --dir "D:\素材" --to webp --quality 90
temu-bot toolbox convert --dir "D:\素材" --to webp --out "D:\输出" --recursive --live

:: Excel 合并
temu-bot toolbox merge --dir "D:\表格"
temu-bot toolbox merge --dir "D:\表格" --add-source-row --live
```

**不加 `--live` 一律只是干跑**（打印会做什么，一个字节都不写）。
控制台那次「执行」是显式带 `live` 的，所以页面上点下去是真的会动文件。
